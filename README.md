# PNG 병합

여러 PNG를 카드로 보고, 회전하거나 순서를 바꾼 뒤 PDF 또는 세로로 이어 붙인 PNG 한 장으로 저장하는 Windows 프로그램입니다.

## 실행

Python이 있는 PC에서는 `실행.bat`을 더블클릭합니다. Pillow가 없으면 자동으로 설치한 뒤 창을 엽니다.

직접 실행할 때는 프로젝트 폴더에서 다음을 입력합니다.

```bat
py -3 -m pip install -r requirements.txt
py -3 main.py
```

실행 파일을 만들 때는 PyInstaller를 사용합니다. 결과물은 `dist\PNG병합.exe`이며, 이 파일은 저장소에 포함하지 않습니다.

```bat
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --clean --onefile --windowed --name "PNG병합" main.py
```

## 사용 방법

| 동작 | 방법 |
|---|---|
| 파일 추가 | **열기** 또는 `Ctrl+O`. PNG를 여러 장 고르면 카드로 붙습니다. 다시 열면 뒤에 추가됩니다. |
| 회전 | 카드의 **좌회전** / **우회전**. 90°씩 돌고 미리보기에 바로 반영됩니다. |
| 순서 변경 | 미리보기나 카드 빈 곳을 클릭한 채로 다른 카드 쪽으로 끕니다. **앞으로** / **뒤로**로 한 칸씩 옮길 수도 있습니다. |
| 목록에서 제거 | 카드의 **빼기**, 또는 **모두 지우기**. 원본 파일은 삭제되지 않습니다. |
| 저장 | **저장** 또는 `Ctrl+S`. PDF와 PNG 중 형식을 고른 뒤 위치를 지정합니다. |

카드 왼쪽 위 번호가 저장 순서입니다.

## 저장 결과

| 형식 | 결과 |
|---|---|
| PDF | 이미지 한 장당 한 페이지 |
| PNG | 번호 순서대로 세로로 이어 붙인 이미지 한 장. 폭이 다르면 가운데로 맞추고, 빈 칸은 흰색입니다. |

기본 파일 이름은 첫 번째 그림 이름 뒤에 `_병합`이 붙습니다.
